# Managing Test Blog Posts with TanStack Query

This Expo app demonstrates CRUD operations using TanStack Query and the JSONPlaceholder API.

## Features

- Fetch all posts with GET
- Create a post with POST
- Fully update a post with PUT
- Partially update a post title with PATCH
- Delete a post with DELETE
- Filter posts by User ID
- Loading and error states

## Technologies

- React Native
- Expo
- TanStack Query
- JSONPlaceholder API

## How to Run

```bash
npm install
npm install @tanstack/react-query
npx expo start
